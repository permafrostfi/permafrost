Token amounts are raw balances divided by 10⁸. Phantom shows xStocks multiplied by the issuer's dividend factor, so its figures run slightly higher.

1. Set up the vault

—

Creates the vault, the PAIF token and the five token accounts. Once only. The name and symbol cannot be changed afterwards.

2. Seed the vault

—

Moves these amounts from your wallet into the vault and creates 25 PAIF that are locked forever. Once only. Every leg must be above zero; the amounts set the basket's starting weights.

3. Change the deposit cap

—

Deposits that would take total supply above the cap are refused. Redemptions are never capped.

4. Apply an upgrade

—

Claude uploads new program code to a buffer and hands the buffer to your address. Paste the buffer address here; the page checks it before you sign. The buffer's rent comes back to your wallet.
